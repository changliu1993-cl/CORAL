Mitigating Object Hallucination in Large Vision-Language Models via False Discovery Controlled Visual Data Splitting

A principled, training-free framework for image-level hallucination control using uncertainty-aware visual data splitting, mirror statistics, and false discovery rate control.

CORAL Framework

METHOD

From visual uncertainty to controlled discoveries

Paired visual views + mirror statistics + image-level FDR thresholding.

01

Uncertainty-Aware Visual Data Splitting

CORAL constructs two paired visual views through sign-symmetric perturbations from a shared Gaussian noise source.

f+v = v + τvZv
f−v = v − τvZv
02

Mirror Statistic

The responses to the paired perturbations are compared to separate stable visual evidence from perturbation-induced randomness.

Δt = |Δ+t + Δ−t| − |Δ+t − Δ−t|
03

False Discovery Rate Control

Negative mirror evidence estimates spurious visual discoveries and determines a data-driven threshold for retaining visually supported predictions.

Target FDR: q = 0.10
Training-Free No additional model training or supervision.
FDR-Controlled Explicit control over false visual discoveries.
Uncertainty-Aware Paired symmetric perturbations quantify visual uncertainty.
Model-Flexible Evaluated across multiple LVLM architectures.

Suppressing unsupported predictions

SCOPE

Reliable grounding with explicit limitations

What CORAL does

CORAL operates on model logits to quantify whether generated visual concepts are consistently supported by the image and applies false discovery control to suppress unsupported predictions.

Current limitation

CORAL cannot be directly applied to black-box commercial APIs that do not expose token-level logits. Future work includes broader relational, attribute, and open-ended hallucination settings.
