Mitigating Object Hallucination in Large Vision-Language Models via False Discovery Controlled Visual Data Splitting

A training-free framework that models visual uncertainty with paired, symmetric perturbations and uses mirror statistics to control false discoveries at the image level.

OVERVIEW

Controlling hallucinations at the image level

CORAL treats object hallucination as a false discovery control problem rather than evaluating each object query independently.

METHOD

Three components, one controlled decision rule

The paper combines uncertainty-aware visual data splitting, mirror statistics, and false discovery rate control.

01

Uncertainty-Aware Visual Data Splitting

Two mirror views are generated from a shared Gaussian noise source using opposite perturbation signs.

f+v = v + τvZv
f−v = v − τvZv
02

Mirror Statistic

The paired logit contrasts capture whether a generated token responds consistently to the two symmetric perturbations.

Δt = |Δ+t + Δ−t| − |Δ+t − Δ−t|
03

False Discovery Rate Control

The negative tail of the mirror statistic is used to estimate spurious visual discoveries and select a data-driven threshold.

SCOPE

What CORAL controls — and where it is limited

Designed for grounded prediction control

CORAL operates on token-level model logits and uses mirror statistics to distinguish stable visual evidence from perturbation-driven noise before FDR-controlled selection.

Current limitation

CORAL cannot be directly applied to black-box commercial APIs that do not expose token-level logits. The paper also identifies relational, attribute, and open-ended generation settings as directions for future work.
