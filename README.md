# CORAL: Mitigating Object Hallucination in Large Vision-Language Models via False Discovery Controlled Visual Data Splitting
We propose a false discovery rate COntRol of object hALlucination (CORAL), a training-free and API-free framework that models visual uncertainty using a data-splitting approach controlled by the false discovery rate.
